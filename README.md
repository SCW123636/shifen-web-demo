# 拾分：大学期末复习 Agent Web Demo

面向大学生的期末复习闭环演示。它不是通用聊天机器人，也不是直接给答案的题库：学生先提交真实作答，系统再给出暂判、错因与评分点证据；只有学习者确认后的有效证据才会更新复习路线与修行 XP。

## 演示内容

- 输入课程、考试日期、目标分数、当前基础和每天可用时间
- 优先展示获授权样例中的可信未做原题
- 支持文字答案与 JPEG/PNG 答题照片
- 展示正确、错因诊断、图片不清和依赖故障四条分支
- 确认前不改变掌握估计或 XP，复核中的证据保持冻结
- 确认后的证据、已做题与 XP 保存在本机浏览器并按证据 ID 去重
- 修仙进度常驻，但只由已确认的有效学习证据驱动

## 数据边界

当前公开 Demo 的题面和评分点来自获授权的预置样例。用户选择的文件只作为本机输入元数据，不上传云端，也不会改变当前演示题包。页面中的掌握度、路线和 XP 都是有界学习估计，不替代学校或教师评价。

## 本地运行

```bash
npm ci
npm run dev
```

默认地址为 `http://127.0.0.1:54825/`。

## 验证

```bash
npm test
npm run typecheck
npm run build
```

推送到 `main` 后，GitHub Actions 会执行测试与构建，并将 `dist/` 发布到 GitHub Pages。

五分钟现场讲解见 [DEMO_SCRIPT_5MIN.md](./DEMO_SCRIPT_5MIN.md)。
